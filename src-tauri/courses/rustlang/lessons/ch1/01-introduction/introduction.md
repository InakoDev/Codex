# Welcome to Rust

Rust is a systems programming language built around one core promise:
you get the speed and control of a language like C or C++, without the
category of bugs — use-after-free, data races, null pointer dereferences —
that make those languages dangerous.

It does this mostly at **compile time**, through a feature called the
*borrow checker*. Instead of trusting you to manage memory correctly (and
catching your mistakes at runtime, if you're lucky), Rust's compiler proves
your code is memory-safe before it ever runs.

## What you'll build toward

Over this course you'll go from "hello world" to writing real Rust:
variables and mutability, ownership and borrowing, structs and enums,
error handling, and eventually small working programs you test yourself.

Each lesson pairs an explanation like this one with a hands-on exercise —
you'll write real code, run it, and see the actual output.

## Before you continue

You don't need any prior Rust experience. Some familiarity with
programming in general (variables, functions, loops) will help you move
faster, but every concept is introduced before it's used.

When you're ready, move to the next step.
